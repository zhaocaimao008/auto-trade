# 实盘启用安全检查清单（最终版）

> **启用实盘前必须逐项确认并打勾。任何一项不满足都不要启用。**

---
## □ 1. API 与数据源

- [ ] AKShare 数据源正常工作（默认，无需配置）
- [ ] 如需 Tushare，`TUSHARE_TOKEN` 已在 `.env` 中配置
- [ ] `check_config()` 启动时无 ERROR 级别警告

## □ 2. EasyTrader 安装与连接

- [ ] Windows 上已安装：`pip install easytrader pywinauto`
- [ ] 券商交易客户端已安装并手动登录
- [ ] `python tests/test_easytrader_login.py` 全部 6 步通过
- [ ] `login()` 返回 True
- [ ] `get_account()` 返回正确的资金数据（与客户端一致）
- [ ] `get_positions()` 返回正确的持仓数据（与客户端一致）
- [ ] `get_latest_price()` 返回 >0 的价格（或确认该券商不支持此查询）

## □ 3. 实盘下单链路测试（is_live=False）

- [ ] `python tests/test_easytrader_order.py` 全程通过
- [ ] Step 4"模拟下单"返回 status=FILLED
- [ ] 模拟下单后 Broker 状态正确恢复（is_live=False）

## □ 4. Broker 动态切换

- [ ] GUI 启动后，底部状态栏显示 Broker 类型（模拟/实盘）
- [ ] 通过 配置 → Broker Tab 可切换 Mock / EasyTrader
- [ ] 切换 Broker 后持仓和账户数据正常刷新

## □ 5. 风控参数已设置

- [ ] 单股止损比例已设置（建议 ≤5%）
- [ ] 单股止盈比例已设置（建议 ≥10%）
- [ ] 最大回撤熔断已设置（建议 ≤8%）
- [ ] 单股仓位上限已设置（建议 ≤30%）
- [ ] 总仓位上限已设置（建议 ≤80%）
- [ ] 风控引擎已启用（RiskManager.config.enabled=True）

## □ 6. 风控与二次确认

- [ ] 手动下单时弹出二次确认弹窗（默认 No）
- [ ] 自动执行有"免确认"复选框控制
- [ ] 未勾选"自动执行免确认"时，每次自动买卖都弹窗
- [ ] 风控在实盘模式下始终生效（不受 trusted 影响）
- [ ] 下单前资金不足/持仓不足时被风控拦截

## □ 7. 紧急停止机制

- [ ] 菜单栏有 **⚡ 安全** 菜单
- [ ] **🛑 紧急停止引擎** 绑定快捷键 `Ctrl+Shift+Escape`
- [ ] 紧急停止后引擎不再执行任何策略
- [ ] **⚠️ 清仓所有持仓** 功能可用
- [ ] 实盘清仓时需要二次确认

## □ 8. 日志与监控

- [ ] `logs/live_trading.log` 文件存在
- [ ] 实盘日志记录了登录和下单事件
- [ ] 应用日志 `logs/app.log` 轮转正常
- [ ] 异常情况会记录到日志

## □ 9. GUI 实盘警告

- [ ] 状态栏显示 **🔴 实盘模式** 红色警告标签
- [ ] 配置对话框中实盘复选框带红色提示
- [ ] 实盘模式下 Broker 状态标签显示"实盘"

## □ 10. 资金安全

- [ ] 实盘账户中只有 **愿意亏损的资金**
- [ ] 首单使用 **最小交易单位**（100 股）
- [ ] 首单选择 **低价股**（降低风险）
- [ ] 已在非交易时段完成全部测试
- [ ] 了解在券商客户端**手动撤单**的方法

## □ 11. .env 文件安全

- [ ] `.env` 已列入 `.gitignore`，不会提交到 git
- [ ] `.env.example` 中不含真实密码
- [ ] 账号密码仅在本机存储

## □ 12. 系统环境

- [ ] 运行机器的系统时间与北京时间一致
- [ ] 网络连接稳定
- [ ] 机器不会自动休眠或关机
- [ ] 券商客户端进程保持运行

## □ 13. 定时调度（可选）

- [ ] 如需自动启停：确认 `SchedulerService` 已启用
- [ ] 自动启动时间：09:20
- [ ] 午间暂停：11:30 → 12:55 恢复
- [ ] 收盘停止：15:05
- [ ] 非交易日引擎自动跳过

## □ 14. 最终确认

- [ ] 模拟交易已运行至少 **5 个交易日**
- [ ] 双均线和 MACD 策略均产生过买卖信号
- [ ] 权益曲线正常绘制
- [ ] 已阅读 `docs/easytrader_guide.md`
- [ ] 心理上已接受可能产生的亏损
- [ ] 已制定应急预案（断网/崩溃/异常信号）
