# 实盘启用安全检查清单

> **启用实盘前必须逐项确认，任何一项不满足都不要启用。**

---

## □ 1. 模拟交易验证

- [ ] 模拟模式（BROKER_TYPE=mock）已连续运行至少 **5 个交易日**
- [ ] 双均线和 MACD 策略均产生过明确的买卖信号
- [ ] 模拟下单、持仓更新、成交记录功能正常
- [ ] 账户权益曲线正常绘制

## □ 2. 风控参数已设置

- [ ] 单股止损比例已设置（建议 ≤5%）
- [ ] 单股止盈比例已设置（建议 ≥10%）
- [ ] 最大回撤熔断已设置（建议 ≤8%）
- [ ] 单股仓位上限已设置（建议 ≤30%）
- [ ] 总仓位上限已设置（建议 ≤80%）

风控参数在 `src/autotrader_app/risk/risk_manager.py` 中配置，也可通过后续的 GUI 配置面板调整。

## □ 3. EasyTrader 连接测试通过

- [ ] Windows 上 `pip install easytrader pywinauto` 安装成功
- [ ] `python tests/test_easytrader_login.py` 全部步骤通过
- [ ] `login()` 返回 True
- [ ] `get_account()` 返回正确的资金数据
- [ ] `get_positions()` 返回正确的持仓数据

## □ 4. 券商客户端已准备

- [ ] 券商交易客户端已安装并手动登录
- [ ] 客户端保持打开状态（easytrader 通过进程通信）
- [ ] 客户端交易密码已确认正确
- [ ] 客户端网络连接正常
- [ ] 客户端显示的资金/持仓数据正确

## □ 5. 资金安全

- [ ] 账户中只有 **愿意亏损的资金**
- [ ] 实盘首单使用 **最小交易单位**（100 股）
- [ ] 实盘首单选择 **低价股**（降低风险）
- [ ] 已在非交易时段完成全部测试

## □ 6. 运行环境检查

- [ ] 运行机器的系统时间与北京时间一致
- [ ] 网络连接稳定（断网会导致策略无法执行）
- [ ] 机器不会自动休眠或关机
- [ ] 建议使用独立机器或云服务器运行

## □ 7. 日志记录已确认

- [ ] 日志目录 `logs/` 存在且可写
- [ ] 日志级别正确（INFO 以上）
- [ ] 了解日志文件的位置和查看方式

## □ 8. 紧急处理方案

- [ ] 知道如何 **快速停止交易引擎**（GUI 停止按钮）
- [ ] 知道如何 **手动撤单**（券商客户端直接操作）
- [ ] 知道券商客服电话
- [ ] 制定了应急预案（断网、崩溃、异常信号）

## □ 9. 实盘二次确认已生效

- [ ] 确认 GUI 状态栏显示 **🔴 实盘模式** 红色标签
- [ ] 手动点击"模拟买入"时弹出二次确认对话框
- [ ] 策略自动执行时弹出二次确认对话框
- [ ] 二次确认对话框默认选项为 **"否"**

## □ 10. 最终确认

- [ ] `.env` 文件已妥善保护（不提交到 git）
- [ ] 已与家人/同事告知正在运行自动交易
- [ ] 心理上已接受可能产生的亏损
- [ ] 今日非极端行情（避开重大政策公布日）
