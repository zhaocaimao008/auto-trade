## 二、风控配置

### □ 2.1 股票池白名单 🔴
- [ ] `RiskConfig.allowed_symbols` 已设置（只允许交易熟悉的股票）
- [ ] 已确认白名单中的股票代码正确
- [ ] 科创板（688xxx）和北交所股票不在白名单中

### □ 2.2 金额限制 🔴
- [ ] 单笔最大金额已设置（建议 ≤5,000 元 ≈ 50 股 × 100 元）
- [ ] 单日最大买入金额已设置（建议 ≤20,000 元）
- [ ] 以上参数已在 `RiskConfig` 中配置

### □ 2.3 交易频率限制 🔴
- [ ] 同一股票最小交易间隔已设置（建议 ≥5 分钟）
- [ ] 风控引擎已启用（`RiskConfig.enabled=True`）

### □ 2.4 止损/止盈 🟡
- [ ] 单股止损比例已设置（建议 ≤5%）
- [ ] 单股止盈比例已设置（建议 ≥10%）
- [ ] 最大回撤熔断已设置（建议 ≤8%）
- [ ] 单股仓位上限已设置（建议 ≤30%）
- [ ] 总仓位上限已设置（建议 ≤80%）
